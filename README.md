# Klavier Trainer

Android-App zum Klavierlernen mit fallenden Noten, Tempo, Händetrennung, Abschnitt-Wiederholung,
Warte-Modus mit Tonerkennung und Fortschritt.

- `web/index.html` – die komplette App-Oberfläche. Wird automatisch über GitHub Pages veröffentlicht;
  die installierte App lädt sie bei jedem Start → Änderungen ohne Neuinstallation.
- `android/` – Android-Hülle (WebView, Mikrofon, Vollbild). Wird bei Änderungen automatisch gebaut;
  die APK liegt unter **Releases → „app“**.

**APK installieren:** `https://github.com/<benutzer>/<repo>/releases/download/app/KlavierTrainer.apk`
auf dem Handy öffnen, herunterladen, installieren.
